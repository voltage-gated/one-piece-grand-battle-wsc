# From TV Animation One Piece: Grand Battle Swan Colosseum 한국어 패치

## 프로젝트 개요

「From TV Animation One Piece: Grand Battle Swan Colosseum」은 원작 애니메이션을 바탕으로 제작되어 2002년 일본에서 발매된 WonderSwan Color용 대전 액션 게임입니다.

이 저장소는 게임 내 텍스트를 한국어로 제공하기 위한 패치와 배포 정보를 관리합니다. 패치별 세부 변경점은 각 릴리즈 페이지에 기록합니다.

## 사용 방법

1. 정품 카트리지에서 직접 추출한 일본판 원본 ROM을 준비합니다.
2. 원하는 릴리즈에서 IPS 패치와 필요한 파일을 받습니다.
3. IPS 패치 프로그램으로 원본 ROM에 패치를 적용합니다.
4. 적용 전후의 파일 정보가 릴리즈 페이지의 호환 정보와 일치하는지 확인합니다.

릴리즈에는 전 캐릭터 해금 세이브 파일도 포함되어 있으며, 사용하는 에뮬레이터의 해당 게임 세이브 데이터 위치에 넣어 사용할 수 있습니다.

원본 ROM 이미지와 패치가 적용된 ROM 이미지는 배포하지 않습니다.

## 배포 및 권리

이 프로젝트는 공식 허가나 보증을 받지 않은 비영리 팬 제작물입니다.

게임과 게임 내 원본 저작물에 대한 권리는 원작자 및 각 권리자에게 있으며, 이 프로젝트는 해당 권리를 주장하지 않습니다. 원본 ROM과 패치된 ROM은 공유하지 마세요.

패치 파일은 원출처를 명시하는 조건으로 수정 및 재배포할 수 있습니다.
